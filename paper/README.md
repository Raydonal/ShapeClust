# The manuscript

LaTeX sources, figures, and the recipe to rebuild both documents.

```
paper/
├── paper.tex             # main manuscript (Elsevier elsarticle class)
├── supplementary.tex     # supplementary material (S.1 - S.8)
├── referencias.bib       # bibliography (177 entries)
├── figures/              # 84 figures, all generated by the package
├── pdf/                  # compiled PDFs
├── results_summary.csv   # the 96 numbers behind every table
└── Makefile
```

## Building

```bash
make            # both documents
make paper      # main manuscript only
make supp       # supplement only
make clean      # remove LaTeX by-products
```

Or by hand:

```bash
pdflatex paper && bibtex paper && pdflatex paper && pdflatex paper
```

The four passes are needed because `cleveref` and `natbib` both resolve on the
second and third runs.

## Regenerating the figures and tables

Nothing in `figures/` is drawn by hand: all 84 files come out of the package.
With `ShapeClust` installed, from the repository root:

```bash
Rscript inst/driver.R          # Monte Carlo grid, resumable; repeat until it
                               #   reports 96 cached chunks (~70 min, 1 core)
Rscript inst/assemble.R        # 48 violin plots + results_summary
Rscript inst/finish_figs.R     # 24 PCA biplots
Rscript inst/missing-figures.R # templates, pre-shape rotation, real-data plots
Rscript inst/real_data_mc.R    # real data over 100 random initializations
Rscript inst/make_tables.R     # rewrites tab_main.tex, tab_supp.tex, tab_real.tex
```

`driver.R` caches each chunk of 25 replications to `paper/cache/`, so it can be
interrupted and resumed; it skips whatever is already on disk. That directory is
git-ignored, since it is regenerable.

## The design, in one table

| | |
|---|---|
| Regimes | Complex Bingham pre-shapes; isotropic landmarks; anisotropic landmarks |
| Landmark counts | k = 4 and k = 24 (Bingham) / k = 34 (landmark regimes) |
| Sample sizes | n = 30, n = 150 |
| Overlap | 1 (well separated), 2 (overlapping) |
| Scenarios | 3 x 2 x 2 x 2 = 24 |
| Replications | 100 per scenario |
| Bootstrap replicates | B = 100 |
| Clusterers | Shape-PAM and Shape-rankkmed, each with and without bagging |

One caveat worth knowing before you change anything: in the Complex Bingham
regime, the concentration needed to hold the group overlap fixed **grows with
the number of landmarks**. Scenario 2 uses λ = 9 at k = 4 but λ = 30 at k = 24;
λ = 9 at k = 24 spreads the distribution so thinly over 23 complex coordinates
that the three groups become indistinguishable by construction, and both
algorithms sit at the chance level of 1/3. This is argued in §5.2 of the paper
and implemented in `bingham_lambda()` in `inst/reproduce-all.R`.
