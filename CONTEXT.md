## 1. The project in one paragraph

A paper adapting **PAM** and **Ranked K-medoids** to **Kendall's 2D shape
space** (intrinsic Riemannian distance) and pairing each with the **BagClust1**
bootstrap ensemble. Validated on a Monte Carlo design of 24 scenarios × 100
replications × B = 100, and on two real datasets. Shipped with a production R
package, **ShapeClust**, whose C++ core makes the whole grid reproducible.

**Working hypotheses** (stated in the introduction, tested in the results):
bagging helps where the base clusterer is *unstable* and the groups overlap;
the higher-variance base clusterer (rankkmed, with its random relocation step)
gains more than PAM; and difficulty — hence the room for the ensemble — grows
with the landmark count at fixed separation.

**Authors (fixed):** Raydonal Ospina (**corresponding**, `raydonal@de.ufpe.br`,
UFBA/LInCa + UFPE/CASTLab) → Inácio Robson Alves do Nascimento (UFPE/CASTLab) →
Getúlio José Amorim do Amaral (UFPE/CASTLab).

## 4. Traps already hit — do not repeat

**The Complex Bingham sampler had two bugs** (fixed; a regression test now
guards both):
- it truncated the k-vector of squared moduli to k−1, **discarding the
  concentration pole** (the last coordinate) → near-uniform noise;
- the group rotation reflected e₁ instead of the pole e_d → all three groups
  came out identically distributed.

Symptom: FMI ≈ 0.33 (chance for 3 groups) **even at λ = 200**, which should be
trivially separable. If that number ever reappears, look here first.

**Concentration must scale with dimension.** Spread over 23 complex
coordinates, λ = 9 leaves the Bingham nearly uniform, so groups are
indistinguishable *by construction*. Calibrated: overlapping scenario uses
**λ = 9 at k = 4** and **λ = 30 at k = 24** (standard-PAM FMI ≈ 0.78–0.93 for
both); λ ≥ 60 at k = 24 saturates at 1.000. Helper: `bingham_lambda()` in
`inst/reproduce-all.R`; argued in §5.2 of the paper.

**The sampler needs two mechanisms.** Kent–Constable–Er simplex truncation is
efficient only for large λ; for small λ its acceptance rate collapses. A batched
uniform-simplex rejection sampler covers the small-λ regime. Both target the
same density; `.cbingham_one()` switches on whether the expected sum of Texp
variates exceeds 0.8.

**One-core sandbox, background jobs killed between calls.** Long runs must be
chunked and resumable — hence `inst/driver.R` (25 replications per chunk, cached
to disk, skips what exists). The full grid is 96 chunks.

**Performance.** Calling C++ once per candidate swap from an R loop was the
bottleneck. `shape_pam_cpp` does the whole sweep in C++: `bagclust1` with
B = 100 went **4.06 s → 0.50 s**. Without this the grid is not feasible.

**`\bibliographystyle` sits in the supplement's *preamble*.** Slicing the file
on that marker duplicated the whole document. Cut on `\bibliography{referencias}`
instead.

## 5. Standing editorial rules

- No absolutist language: no "state-of-the-art", "powerful", "significantly
  delivers", "remarkable". **No "framework"** in our own prose (the single
  occurrence in the PDF is inside Strehl & Ghosh's cited *title*).
- Report the scenarios where bagging does **not** help. The sand-grains null
  result stays; so does the one ρ/d_F disagreement.
- Say **scenario**, never "cell". A scenario is one full configuration of the
  design (regime, k, n, overlap); there are 24.
- Table notation is spelled out: `a → b` means base clusterer alone → same
  clusterer inside BagClust1 with B = 100.
- US English, but respect noun/verb: *analysis / analyses* (noun) vs
  *analyze / analyzes / analyzed* (verb). A careless `sed` once produced
  "Real-world data analyzes". Reference **titles** stay verbatim.
- Page pressure is resolved by **moving content to the supplement, never by
  cutting it**.
- The package is **not on CRAN**. Say so; cite the GitHub repository; keep this
  out of the abstract (it belongs in the methodology).

## 6. Key numbers (all reproduced, none inherited)

Median FMI, overlapping scenario, paired one-sided Wilcoxon, 100 replications:

| Scenario | Shape-PAM | Shape-rankkmed |
|---|---|---|
| Bingham k=4, n=150 | 0.920 → 0.921 (p=0.001) | **0.528 → 0.808** (p<0.001) |
| Bingham k=24, n=150 | **0.747 → 0.842** (p<0.001) | **0.449 → 0.721** (p<0.001) |
| Isotropic k=34, n=150 | 0.585 → 0.591 (p=0.051) | **0.502 → 0.593** (p<0.001) |
| Anisotropic k=34, n=150 | 0.651 → 0.664 (p=0.062) | **0.539 → 0.636** (p<0.001) |

Real data (median over **100 random initializations**, paired Wilcoxon):
- **Orang-utan crania** (`pongof.dat` + `pongom.dat`, 24 F + 30 M, k = 8):
  bagged Shape-PAM RI **0.648 → 0.743** (+14.7%, p<0.001), and its dispersion
  across initializations falls (s: 0.047 → 0.038). VEG/VIG = 1.92.
- **Sand grains** (k = 50, n = 49): VEG/VIG = **0.97** — weak geometric signal.
  PAM unchanged; rankkmed FMI +6.1% (p<0.001). An honest null for PAM.

**ρ vs d_F:** five of six comparisons agree. The exception is Shape-PAM on the
isotropic regime: p = 0.051 under ρ, p < 0.001 under d_F. Same direction, both
distances; the disagreement is about which side of 0.05 a borderline p-value
falls on. Reported, not hidden (Section S.8).

**Scalability:** distance matrix 69 ms at n = 1000, k = 50; Shape-PAM 182 ms in
the same configuration; `bagclust1` near-linear in B, per-replicate cost
flattening at ≈ 41 ms.

Full grid: `paper/results_summary.csv` (96 rows = 24 scenarios × 2 algorithms ×
2 indices).

## 8. Rebuilding everything

```bash
# package
R CMD build ShapeClust && R CMD INSTALL ShapeClust_0.2.0.tar.gz
Rscript -e 'library(testthat); library(ShapeClust); test_dir("tests/testthat")'

# full Monte Carlo grid (resumable, ~70 min on one core), from the repo root
Rscript inst/driver.R          # repeat until it reports 96 cached chunks
Rscript inst/assemble.R        # 48 violins + results_summary
Rscript inst/finish_figs.R     # 24 biplots
Rscript inst/missing-figures.R # templates, pre-shape rotation, real-data plots
Rscript inst/real_data_mc.R    # real data, 100 random initializations
Rscript inst/make_tables.R     # regenerates the LaTeX tables

# manuscript
cd paper && make          # -> pdf/paper.pdf and pdf/supplementary.pdf
```
